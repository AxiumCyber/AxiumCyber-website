AXIUM CYBER LLC WEBSITE
=======================

Files:
- index.html: responsive website
- assets/axium-hero.png: generated Axium Cyber landscape artwork

Preview:
Open index.html in a modern browser. Keep the assets folder beside it.

Contact form:
The form opens a draft in the visitor's default email app. It does not send or store messages.
To receive messages directly, connect a form service or add a backend before publishing.

Publishing:
Upload the entire folder to a static host such as Vercel, Netlify, or your web host.
Replace placeholder business copy/contact details with verified information before launch.
